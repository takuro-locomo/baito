# baito — 医師スポットバイト 効率化プロジェクト

医師向けスポットバイトの求人を集め、**地理的・時間的に連勤できる「効率よく稼げるプラン」**を組むプロジェクト。

## ゴール

単発案件をバラバラに拾うのではなく、**移動と空き時間のロスを最小化した連勤パッケージ**として提案する。

### プランの2パターン

| パターン | 内容 | 最適化の軸 |
|---|---|---|
| **A. 一か所集中型** | 同一施設・同一エリアで連日勤務（例: 健診センター連日、同病院の外来+当直の連結） | 移動ゼロ化・宿泊固定・時給換算の最大化 |
| **B. 地域巡回型（旅行がてら）** | 特定地域を数日かけて巡り、1日1案件＋観光を組み合わせる | 移動経路の一筆書き・宿泊地の最適化・観光価値との両立 |

### プラン評価の指標

- 総収入（交通費・宿泊補助込み）
- **実質時給** = 総収入 ÷（勤務＋移動の総拘束時間）
- 移動コスト（金額・時間）
- 連勤のしやすさ（当直明け→日勤の無理がないか）

## ワークフロー

1. **条件設定**: `条件.md` に希望条件を記録（日程・エリア・科目・単価下限など）
2. **収集**: ユーザーがサイトにログイン → Claude がブラウザ連携で求人を検索・収集 → `data/YYYY-MM-DD_サイト名.md` に保存
   - ログイン（パスワード入力）はユーザー本人が行う。Claude は検索・閲覧・記録のみ
3. **プラン作成**: 収集した案件から連勤プランを組む → `plans/YYYY-MM_プラン名.md`
4. **応募**: ユーザー本人が行う（Claude は応募締切・条件の整理まで）

## 対象サイト

ユーザーがアカウントを持つサイトを登録していく（`条件.md` 参照）。

## フォルダ構成

```
条件.md        ← 希望条件・対象サイト一覧
data/          ← 収集した求人データ（日付_サイト名.md）
plans/         ← 連勤プラン（A案・B案）
```
